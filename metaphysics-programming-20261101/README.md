## 閲覧方法

`metaphysics_programming.html` を保存し、ブラウザで開いてください。本文・図・CSS・JavaScriptはすべてこの一ファイルに入っています。別のサーバー、Python、Node.js、インターネット接続は閲覧に不要です。参考文献の外部リンクを開くときだけ通信が必要です。

画面上部で文字サイズとライト／ダーク表示を変更できます。目次、章末の前後リンク、各章のURLアンカーで移動できます。章への直リンクは、例えば `metaphysics_programming.html#ch13` です。図やコードは画面幅に収まらない場合に横へスクロールできます。検索はPCでCtrl＋Fまたは⌘F、スマートフォンではブラウザの「ページ内検索」を使います。

設定と読書位置はlocalStorageが利用できる環境で保存します。再度開いたときの「続きから」で保存位置へ移動します。位置は段落とその内部の比率で記録します。ファイルの移動、ブラウザの変更、閲覧データの消去、ローカルファイルの扱いによって保存位置が失われる場合があります。外部サーバーへの送信は行いません。

JavaScriptを無効にしても本文・目次・章間リンク・図表を読めます。その場合、文字サイズボタン・テーマ切替・進捗・位置保存は使えません。印刷用CSSを同梱していますが、実際の印刷出力は未検証です。

## 原稿の編集と再生成

読むだけなら下記の作業は不要です。再生成する場合はZIPを展開して、そのフォルダを作業ディレクトリにします。Python 3.12以降、Node.js 22以降を想定しています。制作時のPython実行検証環境はCPython 3.12.14、Markdown変換器はmarked 17.0.5です。

初回に必要な編集用依存関係を導入します。この段階はネットワーク接続が必要です。

```sh
npm install
python3 -m pip install lxml
```

`metaphysics_programming_source.md` を編集します。`## 第N章`、`## はじめに`、`## おわりに` が章の区切りです。本文内の参考文献番号は `[R01](#ref-r01)` の形式です。出典の内容は `references.md` を編集してください。原稿末尾の `<!-- REFERENCES START -->` より後ろは再生成時に `references.md` から同期するため、直接編集しないでください。

コード例は `python` フェンス、その直後に `実行結果：` と `text` フェンスの実行結果を組にします。再生成スクリプトは原稿内のPython例を実際に実行し、結果が一致しなければ停止します。編集したコードが行う操作に注意してください。本版の例は教材用で、例の実行に外部通信は使いません。

```sh
npm run build
npm run check
```

buildは例の実行、シンタックスハイライト、文字数集計、制作記録、HTMLの順に生成します。checkはJavaScriptの構文、読書機能の模擬DOM検査、HTMLの静的検査を行います。これらは実ブラウザの表示検査を代替しません。HTMLを実際に開き、文字・図・目次・操作を確認してください。

既存の原稿に埋め込まれた図は、再生成時に `assets/*.svg` から同期されます。図を変更したい場合は、対応するSVGを編集します。図を作図コードから作り直す場合だけ、追加でmatplotlibを導入して `python3 make_figures.py` を実行してください。図番号・キャプションは `figures.json` にあります。SVGは埋め込み方式なので、HTMLの配布時にassetsフォルダは不要です。

`make_references.py` は初期の出典データを再作成するスクリプトです。`references.md` を直接編集した後に実行すると、その編集を上書きするため、通常の本文再生成には含めていません。`make_report.py` は文字数を再計算結果から取り込みますが、版の日付・検査件数・未確認事項などは編集者が実際の状況に合わせて更新してください。20章以外に構成を変える場合は `build.cjs` と検査スクリプトも修正が必要です。
