## 実務ツール

### Teamcenter BOM 差分比較マクロ

[VBAソースを開く](./BOM比較_列順非依存.bas)

旧BOMと新BOMのExcelファイルを選択し、Teamcenter Excel RoundTripのCustom XMLからBOMを読み取って差分を抽出するVBAマクロです。Excelの列位置ではなくTeamcenter内部の `propertyrealName` を参照するため、列順が変わっても比較できます。レベル＋リビジョン名をキーにLCS（最長共通部分列）で行を対応付け、数量変更、置換、追加、削除を判定し、比較結果Excelを自動出力します。

**ファイル:** `BOM比較_列順非依存.bas`

## このリポジトリの特徴

単なる資料置き場ではなく、製品開発の現場で出てくる問題を、力学・材料・統計・品質・計測・意思決定へつなぎ直すことを狙っています。

特に共通しているのは、次の姿勢です。

- 「経験上そうする」だけで終わらず、背後の現象モデルを考える
- 数式だけで終わらず、何を測れば確かめられるかまで落とす
- 平均値だけでなく、公差・ばらつき・経時変化・量産条件を考える
- 試験を合否判定だけでなく、設計判断のための情報取得として扱う
- 文献知識と教材上の仮定・提案をできるだけ区別する

新しい教材やツールを追加した場合は、このREADMEと `index.html` を入口として更新していく想定です。
