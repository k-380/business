## 未完了

本版は依頼の400〜500ページ相当の教科書規模に達していない。全章は概要ではなく説明・実行・演習を持つが、各章の段階的な手計算、追加事例、失敗例、独立した実務課題の厚みを増やす必要がある。ページ数を水増しせず、以下の内容を拡充する。

1. 各章の実習を小ステップに分け、初学者向けの変数・添字・例外・関数の説明を増補する。
2. 6本の実践補講で、入力アダプター、同期残差と未使用トリガー、5種の補間法、校正共分散とモンテカルロ、多変量候補、チャンク境界を追加した。これらを各章の段階的授業へ統合し、別の条件で失敗する事例を増やす。
3. 変化点検出、モード別基準、窓関数とFFT正規化を独立した実務課題へ発展させる。
4. 本CLIはExcel出力を前提とするメモリ内処理。補講6は境界の検証であり、無制限サイズのストリーミング製品ではない。長い欠損の保留、異常な入力、ファイル間の状態を扱う実装は別設計が必要。
5. Windows/macOSでの実行、第三者の技術査読、実機データでの適用検証は未実施。

## 再開

1. businessリポジトリの最新状態を取得し、このディレクトリのPROGRESS.mdとVERIFICATION.mdを読む。
2. manuscript/chapterXX.mdを編集し、対応するexamples/chapterXX/run.pyと生成元tools/make_examples.pyを更新する。
3. `python tools/verify_examples.py` と `python -m pytest tests -q` を実行する。
4. `python tools/build_book.py` → `python tools/check_html.py` → `python tools/package.py` で再生成する。
5. 公開前に既存index.htmlの他書籍リンクを保持しているか確認し、検証状況と未完了項目を更新する。

未完了項目が解消するまでは「400〜500ページの完成教科書」と表記しない。
