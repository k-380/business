検証記録

検証日：2026-10-28。対象：実行検証版0.1。全24章と6補講の教材として検証した。依頼された400〜500ページ相当の長編教科書への拡充は未完了であり、本記録はその完成認定ではない。

Pythonと計算結果

Python 3.12.14 / Linuxの新規仮想環境へrequirements-lock.txtの24パッケージをインストールした。pip checkで依存関係の不整合なし。Windows/macOSの実機では未検証。

  • 自動テスト：51件。空入力、全欠損、重複・逆転・不規則時刻、無候補、極端値、Excel混在型、異なる長さの結合、250,000行CSVを含む。
  • 独立した数値検証：MADの手計算値、時間重み付き補間、長欠損の不採用、モード境界、アンチエイリアシング、フィルタ振幅・位相、同期ラグの符号、チャンク境界一致を確認。
  • 全24章・6補講の30スクリプトを実行。標準出力はexamples配下のoutput.txt、終了コードはexamples/verification.jsonへ保存。
  • 10教材の生成と検査出力を作成。欠損33点、範囲外2点、飽和35点、停止教材の欠損92点、時刻逆転1箇所、フリーズ21点を独立した期待件数と照合。
  • 承認補間の例では運転中の2点だけを補間し、停止中90点の欠損を保持。変換不能文字列は補間しない。
  • CLIを実行し、Excel出力を再読み込み。既定設定で元の数値と解析用値が一致し、品質フラグ、HTMLレポート、変更履歴、ハッシュ・環境記録が出ることを確認。
  • CSVの完全空白レコード、セル内改行、重複ヘッダーを検査。論理レコード番号とExcelシート行番号を区別する。

テストは選定した条件の検証であり、任意の機器データへの適用保証ではない。未知の形式はアダプターと独立した正解データを追加して確認する。

Chromium 134.0.6998.35 / Playwright 1.51.0で、HTTP/HTTPSへのアクセスを遮断してfile://から開いた。幅1280 pxと390 pxで主要34ページを検査し、68回の表示検査で本文の横はみ出し、画像読み込み失敗、JavaScript例外がないことを確認した。全文検索、解答開閉、コードコピー、明暗切替を実操作して成功した。単一HTMLをA4へ印刷し、172ページを生成、第1章・第24章・演習解答をPDFの抽出本文で確認した。

最新の機械可読結果はtests/browser-results.jsonとtests/html-results.jsonに記録する。印刷ページ数は余白・ブラウザ・フォント・コード折り返しに依存し、商業出版のページ数と同義ではない。画面の見た目を良くするために余白で目標ページ数へ合わせる調整はしていない。

本版は依頼の400〜500ページ相当の教科書規模に達していない。全章は概要ではなく説明・実行・演習を持つが、各章の段階的な手計算、追加事例、失敗例、独立した実務課題の厚みを増やす必要がある。ページ数を水増しせず、以下の内容を拡充する。

  2. 6本の実践補講で、入力アダプター、同期残差と未使用トリガー、5種の補間法、校正共分散とモンテカルロ、多変量候補、チャンク境界を追加した。これらを各章の段階的授業へ統合し、別の条件で失敗する事例を増やす。

  5. Windows/macOSでの実行、第三者の技術査読、実機データでの適用検証は未実施。
